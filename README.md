# Meine Fixkosten

Ein einfacher Fixkosten-Tracker als Web-App: Übersicht mit Kreisdiagramm, Kategorien,
Zahlungsrhythmen, Vertragsenden und Kündigungsfristen, dazu Backup per Kopieren und
Wiederherstellen.

## Datenschutz

- Die App speichert alle Einträge ausschließlich lokal auf deinem Gerät
  (`localStorage` im Browser bzw. in der Home-Bildschirm-App).
- Es gibt kein Konto, keine Synchronisation, keine Analyse, keine externen Aufrufe
  durch die App.
- Wenn du die App entfernst oder die Website-Daten löschst, sind die Einträge weg.
  Nutze die Funktion "Backup kopieren" in der App, um deine Daten zu sichern.
- Bereitgestellt wird die App über GitHub Pages. Beim Aufruf der Seite verarbeitet
  GitHub technisch bedingt Verbindungsdaten (z. B. die IP-Adresse) und legt dazu
  Protokolle an. Details:
  <https://docs.github.com/pages/getting-started-with-github-pages/about-github-pages#data-collection>

## Installation auf dem iPhone

1. Die Seite in Safari öffnen.
2. Auf "Teilen" tippen, dann "Zum Home-Bildschirm".
3. Beim Hinzufügen "Als Web-App öffnen" aktivieren (iOS 17.4+).

Die App funktioniert danach auch offline.
